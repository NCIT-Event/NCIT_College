Accessibility

How this website is built for everyone, and how to tell us about a problem.

Preview. The content service isn't running, so this page shows preview data.

Nepal College of Information Technology wants everyone to be able to use this website, including people who use screen readers, keyboard navigation, magnification or slow mobile connections.

Standard

The website aims to meet the Web Content Accessibility Guidelines (WCAG) 2.1, level AA. Every public page and the dashboard were checked with the axe accessibility engine, at desktop and phone sizes, before launch, and keyboard use was checked by hand.

What we've done

  • Text and buttons meet AA colour contrast; nothing relies on colour alone.
  • Every page works with a keyboard, with a visible focus outline and a "Skip to content" link.
  • The home page banner can be paused and respects "reduce motion" settings.
  • Images that carry meaning have descriptions; forms have labels and clear error messages.
  • Pages work on small phones without sideways scrolling, and stay light on slow connections.

Known limitations

Some uploaded PDFs (for example notices and exam routines) are scanned documents that screen readers can't read. Offices are asked to upload text-based PDFs; if you need a document in another format, ask us.

Tell us about a problem

If something on the website is hard to use, email info@ncit.edu.np or use the contact form, with the page address. We aim to reply within five working days.
