# Photo slots

Drop real NCIT photos here with these exact names: lowercase `.jpg`, about 2400px wide for hero-*, 600–1400px for others (see docs/CONTENT-GUIDE.md), each under ~500 KB. Pages pick them up automatically; until then a labelled placeholder shows.

| File | Where it appears |
| --- | --- |
| hero-campus.jpg, hero-admissions.jpg, hero-techfest.jpg | Home banner slides (landscape) |
| lab-students.jpg | Academics mega-menu (portrait 4:5) |
| news-robotics.jpg, news-convocation.jpg, news-mou.jpg, news-lab.jpg | Home news |
| executive-director.jpg, director.jpg, principal.jpg | Leadership messages (portrait 4:5) |
| campus-library.jpg, campus-lab.jpg, campus-sports.jpg | Home campus life |
| alumni-1.jpg … alumni-4.jpg | Featured alumni (portrait 4:5) |

Department page photos are uploaded from the dashboard (My department / Departments), not placed here. `hod-computer.jpg` stays because the Computer Engineering seed data uses it until the HOD uploads a new one.

The NCIT emblem goes at `frontend/public/assets/img/ncit-logo.png` (transparent PNG, at least 256px).
